GitCandy is a Git hosting service rebuilt on ASP.NET Core and NewLife.Cube, with public/private repositories and two-level team/personal source management.

## Installation

```bash
# Clone the repository and build
dotnet build
```

## Quick start

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## Key features

- Authentication, authorization, encryption and security protections
- Seamless integration with the NewLife ecosystem (XCode/Cube/Remoting)
- Pluggable, extensible architecture for custom development
