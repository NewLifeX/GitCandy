GitCandy — служба хостинга Git, переписанная на ASP.NET Core и NewLife.Cube, с публичными и приватными репозиториями и двухуровневым управлением.

## Установка

```bash
# Clone the repository and build
dotnet build
```

## Быстрый старт

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## Возможности

- Аутентификация, авторизация, шифрование и защита безопасности
- Бесшовная интеграция с экосистемой NewLife (XCode/Cube/Remoting)
- Расширяемая модульная архитектура для собственной разработки
