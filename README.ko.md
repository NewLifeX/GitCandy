GitCandy는 ASP.NET Core와 NewLife.Cube로 재구축된 Git 호스팅 서비스로, 공개/비공개 저장소와 팀·개인 2단계 관리를 지원합니다.

## 설치

```bash
# Clone the repository and build
dotnet build
```

## 빠른 시작

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## 주요 기능

- 인증, 권한 부여, 암호화 및 보안 보호
- NewLife 생태계(XCode/Cube/Remoting)와 원활한 통합
- 플러그인 방식의 확장 가능한 아키텍처
