GitCandy 是基於 ASP.NET Core 與魔方重構的 Git 程式碼託管平台，支援公有/私有倉庫、團隊與個人兩級原始碼管理，免部署即可使用。

## 安裝

```bash
# Clone the repository and build
dotnet build
```

## 快速開始

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## 核心特性

- 認證、授權、加密與安全防護齊備
- 與 NewLife 生態（XCode/Cube/Remoting）無縫整合
- 外掛化與可擴充架構，便於二次開發
