GitCandy は ASP.NET Core と NewLife.Cube で再構築された Git ホスティングサービスで、公開／非公開リポジトリとチーム・個人の二階層管理に対応します。

## インストール

```bash
# Clone the repository and build
dotnet build
```

## クイックスタート

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## 主な機能

- 認証・認可・暗号化・セキュリティ対策を完備
- NewLife エコシステム（XCode/Cube/Remoting）とシームレスに連携
- プラグイン可能な拡張アーキテクチャで二次開発が容易
