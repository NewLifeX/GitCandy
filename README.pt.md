GitCandy é um serviço de hospedagem Git reconstruído sobre ASP.NET Core e NewLife.Cube, com repositórios públicos/privados e gestão em dois níveis (equipe e usuário).

## Instalação

```bash
# Clone the repository and build
dotnet build
```

## Início rápido

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## Recursos

- Autenticação, autorização, criptografia e proteções de segurança
- Integração perfeita com o ecossistema NewLife (XCode/Cube/Remoting)
- Arquitetura extensível e conectável para desenvolvimento próprio
