GitCandy es un servicio de alojamiento Git reconstruido sobre ASP.NET Core y NewLife.Cube, con repositorios públicos/privados y gestión de código por equipos y usuarios.

## Instalación

```bash
# Clone the repository and build
dotnet build
```

## Inicio rápido

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## Características

- Autenticación, autorización, cifrado y protecciones de seguridad
- Integración perfecta con el ecosistema NewLife (XCode/Cube/Remoting)
- Arquitectura extensible y conectable para desarrollo propio
