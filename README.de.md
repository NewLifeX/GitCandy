GitCandy ist ein auf ASP.NET Core und NewLife.Cube neu aufgebauter Git-Hosting-Dienst mit öffentlichen/privaten Repositories und Zwei-Ebenen-Verwaltung für Teams und Benutzer.

## Installation

```bash
# Clone the repository and build
dotnet build
```

## Schnellstart

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## Funktionen

- Authentifizierung, Autorisierung, Verschlüsselung und Sicherheitsschutz
- Nahtlose Integration in das NewLife-Ökosystem (XCode/Cube/Remoting)
- Plug-in-fähige, erweiterbare Architektur für eigene Entwicklung
