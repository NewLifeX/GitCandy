> قد تتأخر هذه الترجمة عن النسخة الصينية.

GitCandy خدمة استضافة Git أُعيد بناؤها على ASP.NET Core وNewLife.Cube، مع مستودعات عامة وخاصة وإدارة على مستويين للفرق والأفراد.

## التثبيت

```bash
# Clone the repository and build
dotnet build
```

## البدء السريع

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## الميزات الرئيسية

- المصادقة والتفويض والتشفير والحماية الأمنية
- تكامل سلس مع منظومة NewLife (XCode/Cube/Remoting)
- بنية قابلة للتوسع والإضافات لتطوير مخصص
