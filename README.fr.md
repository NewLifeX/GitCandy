GitCandy est un service d'hébergement Git reconstruit sur ASP.NET Core et NewLife.Cube, avec dépôts publics/privés et gestion à deux niveaux (équipe et utilisateur).

## Installation

```bash
# Clone the repository and build
dotnet build
```

## Démarrage rapide

```bash
# 配置连接字符串后直接运行
dotnet run --project GitCandy.Web
```

## Fonctionnalités

- Authentification, autorisation, chiffrement et protections de sécurité
- Intégration transparente à l'écosystème NewLife (XCode/Cube/Remoting)
- Architecture extensible et modulaire pour vos développements
